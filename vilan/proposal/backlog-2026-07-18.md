# Vilan Backlog — open items (distilled 2026-07-18)

Distilled from [`backlog.md`](backlog.md), which stays as the historical record (shipped
items, their full context, the lessons recorded alongside them). This file carries **open
work only**, simplified. Ids continue the old file's stable numbering: a carried id is the
same item; ids marked **NEW** are new or split-out work; retired numbers stay retired.
Sizes S/M/L/XL; unordered within a section. Per `CLAUDE.md`: each non-trivial item gets a
formal definition + pinned tests before implementation.

**Restructure, 2026-08-03**: this file used to carry both open work and full ship
records side by side — about 70% of its lines were shipped items whose arc had
long since closed, which is why "open work only" had stopped being true. Every
entry that was fully SHIPPED/CLOSED as of this date had its complete body moved
**verbatim** to [`backlog.md`](backlog.md) (a new dated section there), leaving a
one-line tombstone here (`N. **Title — SHIPPED <date>** (<commit>; record:
backlog.md / <proposal>.md)`) — nothing was deleted, only relocated. Entries with
a shipped core but a still-live open tail (A7, A8, A16, C1, ...) kept their body
here.

**Status convention.** Every remaining entry below starts with a `STATUS:` line,
immediately after its title, one of:
- `STATUS: OPEN` — no known blocker, free to pick up.
- `STATUS: OPEN (blocked: <what>)` — genuinely stuck on a named prerequisite.
- `STATUS: OPEN (proposal-first)` — needs a design doc before code, per
  `CLAUDE.md`'s "prove a feature before implementing it".
- `STATUS: DEFERRED (<why/trigger>)` — deliberately not being worked, with the
  condition that would revive it.

**Why:** the reconciliation that produced this restructure found that a title's
own SHIPPED/CLOSED marker is not reliably greppable — several multi-line titles
carried the marker on their *second* line, invisible to a naive one-line
`grep`, and several entries simply stayed open for days after their arc actually
shipped because nothing came back to mark them. A guaranteed, fixed-position
`STATUS:` line (always immediately after the title, never buried mid-paragraph)
is the fix: a one-line grep of any entry's opening now tells the truth, and
"forgot to close it" becomes visible the next time this file is swept rather
than staying silent indefinitely.

## C. Memory model

*Frame: `claims-and-epochs.md` (2026-07-18) — the one law behind all of it (a claim is
valid while its owner's epoch is unchanged; views = static proof, handles = dynamic
