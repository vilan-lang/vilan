`class` is B485's question — typing/semantics, ownership class, visibility/linkage, tooling only, code generation — for a MARKER; a word that marks nothing is a construct, a literal, a name or a clause. ## 2. Where each marker is accepted

Rows: every MARKER (the five classes) and every contextual keyword. Cells: `✓` parses and analyzes clean; `aN` parses and the analyzer refuses (note aN); `sN` the parser refuses with a rule of its own, a steer (note sN); `·` the parser refuses with no rule (a generic "found X expected Y"). A position with two programs (a block body and a `;` body) answers with the better.
